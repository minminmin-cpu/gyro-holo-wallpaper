Set live wallpaper

设为动态壁纸

前端页面不能直接修改系统壁纸，需要由同 APK 内的 WallpaperService 接管。

  1. 生成本页 Profile 并落盘到应用私有目录
  2. 写入 active_profile_id
  3. 跳转系统「设置 → 壁纸 → 动态壁纸」
  4. 选择本应用并确认；之后倾斜手机即可看到闪光跟随

注意：多数 ROM 的动态壁纸只作用于主屏，锁屏通常是静态帧。
